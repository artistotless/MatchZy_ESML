## Что это?

Файл конфигурации матча содержит все, что нужно MatchZy и вашему серверу для проведения серии. Сюда входит закрепление
игроков за правильной командой и стороной, выбор карты(карт) и настройка игровых правил.

**Примечание:** MatchZy можно использовать для pug/scrim/practice и без настройки матча (если `matchzy_kick_when_no_match_loaded` установлен в `false`). Настройка матча нужна только тогда, когда вы хотите провести серию и закрепить игроков за нужными командами и сторонами.

В этой документации показано, как настроить матч в MatchZy с помощью JSON-файла (структура JSON приведена ниже).
Доступны 2 команды для загрузки матча:

1. `matchzy_loadmatch <filepath>`: загружает JSON-файл конфигурации матча относительно директории `csgo`.
2. `matchzy_loadmatch_url <url> [header name] [header value]`: загружает удаленную конфигурацию матча (в формате JSON), отправляя HTTP(S) `GET` по указанному URL. Опционально можно передать HTTP-заголовок и его значение через аргументы `header name` и `header value`. Все аргументы нужно указывать в кавычках (`""`).

2. `matchzy_loadmatch_url "https://<url>/astralis_vs_navi_27.json"`


## Текущие ограничения

1. Тренеров нельзя добавить напрямую через эту конфигурацию матча. Чтобы добавить тренера, добавьте его в `"players"` нужной команды, а затем используйте на сервере команду `.coach <teamside>`.
2. Сейчас поддерживается только Steam64id.

Эти ограничения планируется устранить в ближайших обновлениях! :D
